## Тезис (приятельский трек)

1. **PAL** — жизнь коробки **внутри** portal Cosmoport (пак `cosmoport-custom`), не дубль `product-forks` и не бренд коробки.  
2. As-is portal даёт карточку / команду / ЖЦ / CI-сканеры / сток находок; для роли ИБ это **не** операторский инструмент проверки (см. Stage 2).  
3. Пак ведёт скелет сущностей (app → build → deploy → URL, notify, RBAC) и later-стык с коробкой; **пайп священен**, подмена BRPO — стена.  
4. Реплика admin/notifications — «как у них по сущностям, лучше по смыслу»; UI портала не копировать как долг.  
5. Если когда-то созреет hub — только полный 2FA и отдельное решение; до того PAL остаётся **приятелем**, не другом.
