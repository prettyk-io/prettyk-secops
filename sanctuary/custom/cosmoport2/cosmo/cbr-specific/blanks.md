# Бланки ТЗ и акта (spaceport)

Ровно **два** бланка. Letterhead и отраслевые формулировки — только в скачиваемом файле, не в хроме Editor.

## Кнопки

| № | Бланк | Когда | Где в UI |
|---|---|---|---|
| **1** | Техническое задание | до выполнения работ | вкладка **Регламент** → «Зафиксировать техническое задание» |
| **2** | Акт проверки | после выполнения работ | вкладка **Результаты** → «Скачать акт проверки» |

Перед выгрузкой — validate-gate (конструкторы + схема манифеста). Секреты redact (`***`).

По кнопке уходит один файл: **HTML**.

## Конвейер

1. `buildBlankPayload` — снимок формы + redact + дерево explorer.  
2. `blankFields` + [`profile.ts`](profile.ts) — view-model (контур, нормы, шапка).  
3. `blankMarkdown` — тело (внутренний MD).  
4. `blankHtml` — GFM→HTML + шапка из [`letterheadData.ts`](letterheadData.ts).  
5. Download HTML.

## Подписи

По схеме ОРД (ГОСТ Р 7.0.97): слева должность, по центру линия личной подписи, справа расшифровка (инициалы, фамилия); под каждым полем — пояснение мелким кеглем.

Шаблон: `res-blank-0.6` (поле `BLANK_TEMPLATE_VERSION` в `frontend/src/results/types.ts` на этой ветке).

## Поля объекта

- **Цели для проверки безопасности** — только основной URL (`base_url_override`).  
- **Дополнительно запрошенные границы для проверки** — `allowed_extra_domains`.  
- **Сведения о контуре для тестирования** — строка из `TESTING_CONTOUR_STATEMENT` в [`profile.ts`](profile.ts).

## Стиль HTML

Тело как preview Markdown на GitHub (воздух, мягкие таблицы).  
Сверху — горизонтальный логотип брендбука **D10 RU gray** (~80 px по высоте, без рамки/плашки) + реквизиты справа.  
Рамки — только у сводной таблицы в акте.

## Термины

- **перепроверка**, не «ретест»;  
- без жаргона стенда («прогон») в тексте бланка;  
- метод: «чёрный» / «серый» ящик.

Нормативные формулировки — только в [`profile.ts`](profile.ts).

## Код на ветке

| Модуль | Роль |
|---|---|
| `frontend/src/results/blank*.ts` | Сборка payload / MD / HTML (без дублирования отраслевых строк) |
| `frontend/src/App.tsx` | handlers кнопок |
| `Toolbar` / `ResultsWorkspace` | опциональные кнопки |

Импорт профиля: alias `@cbr/*` → `docs/cbr/*` (vite + tsconfig).
