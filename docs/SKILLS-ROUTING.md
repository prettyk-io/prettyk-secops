## 5. Ваши проёбы (чтобы не повторять)

Тычки в конкретную тупизну — вы это уже делали, больше не делайте:

### Проёб 1: переписали форму/студию/интеграции вместо «выдрать RJSF»
- **Что было:** Максим сказал «просто портируем, выдрав RJSF». Вы построили всё с нуля.
- **Следствие:** полный откат, `/to-sanitize`, потерянное время.
- **Разбор:** [`docs/investigation-vnext-fuckup.md`](investigation-vnext-fuckup.md). Читать всем.
- **Правило:** «выпилить X» ≠ «заменить с нуля». Сначала скриншот «как было», потом «как станет», утвердить — только потом кодить.

### Проёб 2: путались в портах
- **Что было:** путали Editor-порт с мёртвым портом старой эпохи.
- **Истина (бетон): CANON → [`sanctuary/canon/stand-port-meta.md`](../sanctuary/canon/stand-port-meta.md)** — единственный источник.
- **Правило:** порт Editor брать **только** из `vite.config.ts`, не хардкодить руками. Проверять порт через `netstat -ano | findstr :PORT`. Никогда `Get-NetTCPConnection` (не видит IPv6-слушателей `[::]`).

### Проёб 3: браузер в мелком окне
- **Что было:** CDP Chrome открывался в окне 159×27, всё остальное белое.
- **Причина:** Chrome жил со старым мёртвым URL и запомнил размер error-page. `ping` отвечал «жив», поэтому его не перезапускали.
- **Правило:** `ping` жив ≠ окно корректно. `state` → если `innerW < 800` → перезапустить CDP Chrome:
  ```powershell
  powershell -NoProfile -ExecutionPolicy Bypass -File C:\cursor-buddy\Flow\Current\blitz-auth\cdp\reload-cdp.ps1
  ```
  Никакие `resizeTo` / `clearDeviceMetricsOverride` это не чинят. Только перезапуск.
- **Порядок всегда:** `ping` → `state` (вьюпорт ОК?) → действовать.

### Проёб 4: открыли URL через вебвью IDE вместо CDP
- **Что было:** 16 авг открыли Allure `:5050` через MCP-браузер IDE (`browser_navigate`/`browser_snapshot`), хотя контур на CDP Chrome `:9222`.
- **Корень:** в голове был «запрет», а не «путь». Запрет оставил вакуум → мозг сам заполнил его первым попавшимся браузером.
- **Правильный путь (если → то):** URL на хосте → CDP `:9222` (`browser-hands-pure`). URL на VM → SSH+CDP (`browser-hands-remote`). Точка входа одна: `local.ps1`. Других путей нет — не «запрещено», а «не нужны, когда есть правильный». Канон: rule [`browser-cdp-only.mdc`](../.opencode/rules/browser-cdp-only.mdc) (alwaysApply).

## 6. Boot chain (каждый раз, перед задачей)

```text
1. Прочитай NEW_AGENT_MANDATORY.md (если первый раз).
2. Определи трек по сигналам задачи (UI? браузер? дебаг? стек?).
3. Открой нужный глобальный скилл (таблица в §2).
4. Только потом трогай код.
```

Если непонятно, какой скилл — **спроси**, не угадывай. Угадывание скилла = та же тупизна, что и угадывание порта.
