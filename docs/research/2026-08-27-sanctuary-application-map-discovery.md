## 1. Продуктовая философия и метафора: «Тактический радар, а не мёртвая диаграмма»

В сложных киберсек- и DevSecOps-платформах визуальные схемы часто деградируют в один из двух антипаттернов:
1. **«Статичный могильник» (Mermaid / PNG в репозитории):** Устаревает через 2 дня после коммита, никто не обновляет, связи врут.
2. **«Бесконечное спагетти-болото» (Giant Infinite Canvas на 500 нод):** Открываешь — 1500 стрелок пересекают друг друга, 40 FPS, рябит в глазах, оператор теряет контекст через 10 секунд и закрывает вкладку.

В PrettyK и Святилище (Sanctuary) мы утверждаем канон **«Тактический радар Обители»**:

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  SANCTUARY TACTICAL RADAR                                    [ 1:Arch | 2:Flow | 3:Live | 4:Parity | 5:Idea ] │
├──────────────────────────────────────────────────────────────────────────────┤
│  [ L0: Sanctuary ] ➔ [ L1: PrettyK Core ] ➔ [ L2: Studio v2 ]                │
├──────────────────────────────────────┬───────────────────────────────────────┤
│                                      │  TACTICAL INSPECTOR & IDEA FORGE      │
│     ┌──────────────────────────┐     │  ───────────────────────────────────  │
│     │   ✨ Studio v2 Canvas     │     │  Узел: [ Studio v2 Root ]             │
│     │   (ScenarioDeckStore)    │     │  Статус: 🟡 30% Native / 70% Mock     │
│     └────────────┬─────────────┘     │  Маршрут: #/studio-v2                 │
│                  │                   │                                       │
│        ┌─────────┴─────────┐         │  Связи (3 входящих, 4 исходящих):     │
│        ▼                   ▼         │  ➔ [CheckWorkspace Bridge] (durable) │
│  ┌───────────┐       ┌───────────┐   │  ➔ [BuddyDockController] (64 tests)  │
│  │  Monaco   │       │  Browser  │   │  ➔ [ScenarioDeckStore] (active)      │
│  │  CodePane │       │  Stage    │   │                                       │
│  └───────────┘       └───────────┘   │  ⚡ Live Health: SSE Stream OK (12ms)  │
│        │                   │         │                                       │
│        └─────────┬─────────┘         │  💡 ФОРМУЛИРОВАТЬ ИДЕЮ:               │
│                  ▼                   │  [ + Создать задачу в бэклог (GWT) ]  │
│        ┌───────────────────┐         │  [ ↗ Перейти на экран #/studio-v2 ]   │
│        │ 🤖 Buddy Dock     │         │  [ 📖 Открыть канон в Sanctuary ]     │
│        └───────────────────┘         │                                       │
└──────────────────────────────────────┴───────────────────────────────────────┘
```

### 4 столпа тактического радара:
1. **Закон когнитивной чистоты (Rule of 7±2):** На любом уровне масштаба оператор видит не более 5–9 ключевых узлов. Всё остальное свертывается в семантические кластеры.
2. **Семантический зум (Semantic Zoom):** Колёсико мыши или клик по узлу не просто приближает пиксели, а **меняет уровень абстракции** (C4-модель: Храм ➔ Системы ➔ Поверхности ➔ Модули/Контракты).
3. **Мульти-линзы (Multi-Lens Projection):** Один и тот же граф можно просветить 5 разными лучами (Архитектура, Пользовательский поток, Живая телеметрия, Статус миграции, Линза идей).
4. **Двусторонний мост к действию (Actionable Radar):** Клик по узлу позволяет не просто поглазеть, а:
   - Мгновенно телепортироваться на реальный экран платформы (`#/studio-v2`, `#/checks/:id/studio`, `#/admin`).
   - Сформулировать новую архитектурную мысль или эпик с автогенерацией контекста.
   - Увидеть честный статус покрытия тестами и легаси-долг.

## 2. Иерархия масштабирования: C4-адаптация для PrettyK

Вместо плоской карты вводим 3 фундаментальных эшелона глубины:

```
                  ┌─────────────────────────────────────┐
                  │ LEVEL 0: SANCTUARY LANDSCAPE        │
                  │ Обитель, Братья, Контуры, Инфра     │
                  └──────────────────┬──────────────────┘
                                     │ Semantic Drill-down
                                     ▼
                  ┌─────────────────────────────────────┐
                  │ LEVEL 1: PRETTYK PRODUCT TOPOLOGY   │
                  │ Studio, Editor, Buddy, Engine, Lab  │
                  └──────────────────┬──────────────────┘
                                     │ Focus / Sub-graph
                                     ▼
                  ┌─────────────────────────────────────┐
                  │ LEVEL 2: COMPONENT & CONTRACT DEPTH │
                  │ Canvas, Monaco, Explorer, CDP, SSE  │
                  └─────────────────────────────────────┘
```

### Уровень 0: Sanctuary Landscape (Макро-Обитель)
Верховный взгляд Хранителя Алтаря на все домены экосистемы:
- **`PrettyK Pure Box`** — сканерный контур и рабочие интерфейсы.
- **`Buddy Agent Runtime`** — локальный автономный интеллект и оркестрация задач.
- **`Canon & Sanctuary Store`** — Алтарь побед, 2FA-скрижали, `INDEX.md`, канонические контракты.
- **`Local Lab & SecOps Stack`** — Docker Compose, ZAP Demon `:8080`, Allure3 `:5050`, DefectDojo `:8081`, Juice Shop `:3000`.
- **`Durable Storage & Secrets`** — PostgreSQL (SoT), Valkey (Dispatch/PubSub), MinIO (Evidence S3), OpenBao (KMS).
- **`External World & Bridges`** — Discord Bot Gateway, Host CDP Chrome `:9222`, BankVM / Gap2 Remote SSH.

### Уровень 1: PrettyK System Map (Продуктовая анатомия)
Анатомия сканерной платформы, показывающая, как связаны главные функциональные монолиты:
- **`Studio v2` (`#/studio-v2`)** — визуальная сборочная лаборатория сценариев и проверок.
- **`Editor Reborn` (`#/checks/:id/studio`)** — монолитный Monaco-конструктор с 6 корнями Explorer и DSL-кодеком.
- **`CheckWorkspace Bridge`** — единая транзакционная шина (Draft persistence, Commit Engine, Semantic Diff).
- **`Browser Stage & CDP Wire`** — живой мост к Chrome `:9222`, захват кликов, инспекция DOM/AX, Discovery overlay.
- **`Buddy CO-PILOT Dock`** — штурманский док (LaunchpadHero, SkeletonCard, LiveDiffBanner, StepRadar, EvidenceMatrix).
- **`Execution Plane & Fuzzer`** — Playwright Browser Core, ZAP Active Scanner, Fast HTTP Fuzzer, Har Importer.
- **`Telemetry & Evidence Bridge`** — Live Server `:8767` (SSE), Evidence Chain (`intent ➔ run ➔ finding ➔ artifact`).
- **`Admin & Control Plane` (`#/admin`)** — реестр приложений, целей, гейт-политик и прогонов.
- **`Legacy Reference Archive`** — замороженный снимок старого монолита (`docs/archive/studio-editor-legacy/`).

### Уровень 2: Surface Topology & Contracts (Микро-мир под капотом)
Детализация конкретной поверхности при максимальном зуме (например, зум в **Studio v2**):
- **`Canvas v2`** — визуальный граф шагов на `ScenarioDeckStore` + `scenarioStepModel`.
- **`Explorer v2 (TreePanel)`** — живое дерево 6 корней (`pages`, `scenarios`, `fuzzers`, `modules`, `connectors`, `auth`).
- **`CodePanel (Monaco Editor)`** — редактор конструктора, автодополнение, подсветка синтаксиса, Gutter Play `[▶]`.
- **`BrowserPanel (Stage PiP)`** — вьюпорт живого браузера, подсветка hover, кнопки Record / Inspect / Take Control.
- **`Run Console (BottomDrawer)`** — реальная шина логов и SSE-событий вместо захардкоженных заглушек.
- **`BuddyDockController`** — контроллер фаз (`idle`, `thinking`, `waiting`, `running`, `done`, `error`), связывающий `BuddyEngine` и виджеты.
- **`Validation Engine`** — клиентская + серверная валидация (`validateConstructorBackend`) с маркерами ошибок.

## 3. Пять специализированных линз (Multi-Lens Views)

Оператор переключает линзы горячими клавишами `1`, `2`, `3`, `4`, `5` или через верхний Segmented Control. Граф мгновенно перекрашивается и перестраивает видимые связи:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  [ 1: Architecture ] [ 2: Operator Flow ] [ 3: Runtime ] [ 4: Parity ] [ 5: Idea Lens ] │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 1. Архитектурная линза (Architecture Lens) — Клавиша `1`
- **Фокус:** Владение кодом, границы пакетов, файловая структура и направление импортов.
- **Что подсвечивает:** 
  - `frontend/src/studio/` ➔ `frontend/src/buddy/` (UI потребляет движок через `adapters.ts`).
  - `frontend/src/terminal/` ➔ `orchestrator/browser/` (CDP-клиент общается с FastAPI).
  - Изоляция AirGap: граница, за которую запрещено выходить сетевым вызовам.
- **Цветовой код:** Slate/Blue (структурный покой).

### 2. Линза пути оператора (Operator Flow Lens) — Клавиша `2`
- **Фокус:** Сквозной бизнес-процесс создания и прогона проверки безопасности.
- **Цепочка шагов:**
  ```text
  [ Target App ]
        │
        ▼
  [ 🌐 Launchpad / Discovery ] ──▶ [ 📐 Skeleton Extraction ]
                                            │
                                            ▼
  [ ✨ Monaco / Canvas Edit ]  ◀── [ 🤝 Review Proposal ]
        │
        ▼
  [ ⚡ Bounded Run / Fuzz ]
        │
        ▼
  [ 🛡️ Evidence Evaluation ] ──▶ [ 📄 Export / Findings ]
  ```
- **Цветовой код:** Изумрудно-зеленый градиент, анимированные направленные стрелки.

### 3. Линза живого рантайма (Runtime & Telemetry Lens) — Клавиша `3`
- **Фокус:** Активные сетевые сокеты, порты, фоновые демоны и здоровье компонентов в реальном времени.
- **Что видно прямо на нодах:**
  - `Vite Editor`: `:5173` (🟢 HTTP 200 / Alive)
  - `Playground API`: `:8765` (🟢 Alive)
  - `Live SSE Engine`: `:8767` (🟢 SSE Pulse)
  - `Chrome CDP`: `:9222` (🟢 Maximize Viewport 1707x825)
  - `ZAP API`: `:8080` (🟢 Demon Ready)
  - `Target Juice Shop`: `:3000` (🟢 Reachable)
- **Цветовой код:** Пульсирующий Cyan `#22D3EE` и Violet. При падении порта нода загорается тревожным Crimson `#EF4444`.

### 4. Линза миграции и паритета (Migration & Parity Lens) — Клавиша `4`
- **Фокус:** Честный аудит готовности v2 против старого монолита (ликвидация 30%-го макета).
- **Светофор узлов:**
  - 🟢 **100% Native v2:** Узел полностью переписан, автономен, протестирован (`ScenarioDeckStore`, `BuddyDockController`, `BuddyEngine`).
  - 🟡 **30% Hybrid / Mock:** Узел имеет визуальную оболочку, но под капотом заглушки или неполный функционал (`TreePanel`, `CodePanel`, `BrowserPanel`).
  - 🔴 **Legacy Only (В архиве):** Функционал живёт только в `docs/archive/studio-editor-legacy/` и требует переноса (`StudioBlocksTree CRUD`, `LSP Monaco Language`, `StepDebuggerPane`).
- **Цветовой код:** Трехцветный аудит-светофор.

### 5. Линза генератора идей (Idea Lens & Brainstorm HUD) — Клавиша `5`
- **Фокус:** Формулирование новых архитектурных мыслей и задач без путаницы.
- **Поведение:** Клик по любому компоненту ➔ справа открывается панель «Idea Forge»:
  - Текущие ограничения компонента.
  - Список связанных открытых карточек в бэклоге.
  - Поле быстрой записи идеи с автоподстановкой контекста:
    > *«Хочу добавить в [Browser Stage] автоматический снимок DOM-дерева при каждом 401-ответе...»*
  - Кнопка **«Сгенерировать GWT-карточку»** (форматирует мысль по правилу ЧИСТО для Keeper).

### Стили соединительных ребер (Edge Topology):
1. **Data Stream (Активный поток данных):** Неоновая циановая линия с бегущими светящимися точками (SVG `stroke-dasharray` анимация). Скорость точек отражает частоту событий.
2. **Structural Dependency (Архитектурная связь):** Тонкий сплошной графитовый провод с акцентом при наведении курсора.
3. **AirGap Security Barrier (Рубеж изоляции):** Двойная пунктирная линия с янтарно-фиолетовым градиентом, символизирующая запрет на выход во внешнюю сеть.
4. **Focus Dimming:** При выборе одного узла все нерелевантные ноды и связи приглушаются до 10% прозрачности, исключая визуальный шум.

## 5. Декларативная схема данных (Single Source of Truth)

Карта не рисуется вручную и не хардкодится в Canvas. Она парсится из строго типизированного JSON-манифеста:  
`sanctuary/system-map.json` (корень репо, рядом с `ALTAR.md` и `INDEX.md`).

> **Важно:** карта строится на канонических маршрутах (`#/checks/<id>/studio`, `#/checks/<id>/editor`,
> `#/checks/<id>/studio-old`, `#/checks/<id>/editor-old`), а не на временном `#/studio-v2`.
> Поэтому Manifest + Engine пакеты идут следующим скоупом после завершения STU-RAILS.

```typescript
export type SystemLevel = 'landscape' | 'system' | 'surface' | 'component';

export type NodeStatus = 
  | 'native_v2'    // 🟢 100% готов
  | 'hybrid_mock'   // 🟡 30% фасад, требует долива
  | 'legacy_only'   // 🔴 Только в старом монолите
  | 'infrastructure'// 🔵 Служебный слой (БД, брокер, докер)
  | 'sealed_canon'; // 🏛️ Запечатанный канон Святилища

export type LensVisibility = 'architecture' | 'flow' | 'runtime' | 'parity' | 'ideas';

export interface MapPortMeta {
  port?: number;
  protocol?: 'http' | 'ws' | 'sse' | 'cdp' | 'tcp';
  healthEndpoint?: string;
  expectedStatus?: number;
}

export interface SanctuaryMapNode {
  id: string;
  label: string;
  subtitle?: string;
  level: SystemLevel;
  parent?: string;           // ID родительского кластера для семантического зума
  status: NodeStatus;
  route?: string;            // Маршрут в приложении (#/studio-v2, #/admin)
  sourcePaths?: string[];    // Пути к коду (frontend/src/studio/...)
  docsRef?: string;          // Ссылка на markdown-документ
  portMeta?: MapPortMeta;    // Привязка к живому порту стенда
  lenses: LensVisibility[];  // В каких линзах отображается узел
  position?: { x: number; y: number }; // Базовые координаты сетки
  metrics?: {
    testCount?: number;
    loc?: number;
    completionPercent?: number;
  };
  backlogRefs?: string[];    // Привязанные задачи из docs/backlog.md
}

export interface SanctuaryMapEdge {
  id: string;
  source: string;
  target: string;
  label?: string;
  type: 'data_stream' | 'dependency' | 'airgap_barrier' | 'user_step';
  lenses: LensVisibility[];
  bidirectional?: boolean;
}

export interface SanctuarySystemMap {
  version: string;
  lastUpdated: string;
  nodes: SanctuaryMapNode[];
  edges: SanctuaryMapEdge[];
}
```

## 6. Пользовательский интерфейс и точки входа

Карта встраивается в экосистему PrettyK в трёх равноправных формах:

### А. Полноэкранный командный пункт Святилища (`#/sanctuary/map`)
* Доступен из главного меню, хедера или экрана Алтаря.
* Полный интерактивный режим: колесо зума, переключатель линз, поиск узлов через `Ctrl + F`, панель генерации идей.

### Б. Быстрый тактический оверлей (`Ctrl + M` / `Cmd + M`)
* Мгновенно всплывает поверх любого экрана (Studio, Editor, Admin) с эффектом размытия заднего плана.
* Подсвечивает **«Ты находишься здесь»** (текущий экран выделен неоновым маяком).
* Позволяет за 2 секунды сориентироваться, переключить контекст или кликнуть по соседнему модулю для телепортации.

### В. Виджет штурмана в Buddy Dock (`MapMiniRadar`)
* Компактный изометрический радар в нижней части дока Buddy, показывающий текущую фазу прогона в масштабе всей системы.

## 7. Этапы реализации и нарезка на исполнителей (Boss & Flash)

Реализация делится на 2 параллельных инженерных пакета без взаимных блокировок:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ Boss (Heavy Engine & Layout Core)     │ Flash (Visual Shaders & HUD UI)     │
├───────────────────────────────────────┼─────────────────────────────────────┤
│ MAP-1: TypeScript Schema & Validator  │ MAP-4: Tactical Canvas & Grid       │
│ MAP-2: Graph Layout & Semantic Zoom   │ MAP-5: Cyberpunk Node & Pulse Shaders│
│ MAP-3: Telemetry & Port Ping Bridge   │ MAP-6: Idea Forge Drawer & Omnimodal│
└───────────────────────────────────────┴─────────────────────────────────────┘
                                   │
                                   ▼
             MAP-7: Joint E2E Acceptance & Teleport Routing
```

### Пакет Boss (Heavy Architecture & Graph Engine) — 11h

## 8. Критерии приёмки и DoD (Глазами Хранителя)

1. **Мгновенная ориентация:** Открыв карту, оператор за 3 секунды видит разницу между старым монолитом, Studio v2 и движком Buddy.
2. **Честный статус:** Ни один 30%-й макет не помечен как 🟢 Native. Статусы соответствуют реальному коду.
3. **Глубина зума:** Работает честный переход `L0 (Обитель) ➔ L1 (PrettyK) ➔ L2 (Studio v2)`.
4. **Телепортация:** Клик по кнопке «Перейти на экран» переводит роутер на реальную рабочую страницу.
5. **Генератор идей:** Записанная в Idea Forge мысль генерирует чистую Markdown-заготовку с GWT-сценарием и правилом ЧИСТО.
6. **Быстрый доступ:** Нажатие `Ctrl + M` в любом месте системы открывает тактический радар поверх экрана за <150ms.
7. **Производительность:** Плавный зум и перемещение графа без просадок FPS и утечек памяти.
