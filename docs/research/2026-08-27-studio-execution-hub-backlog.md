## Intent

Ликвидировать зоопарк вкладок — Studio `:5173`, Monitor `:8767`, noVNC/Grid `:7900`.  
Studio становится единственным центром: **собрал → запустил → увидел живое исполнение → покадрово перемотал → разобрал с Buddy → исправил**.

Два PoC-мажора. Не надо четырёх.

# Major 1: `EXECUTION-HUB-POC` — поглотить Monitor и Grid в Studio

**Что:** После Run Studio переходит в Execution View с деревом шагов, логами, scanner-алертами и живым экраном браузера Grid. Отдельные вкладки `:8767` и `:7900` больше не нужны.

**Зависимости:** нет — поверх существующего Live Server SSE и BrowserPanel.

---

### 1.1. Execution View внутри Studio

**Intent:** Оператор запустил прогон — Studio сама показывает ход без перехода на `:8767`.

| | |
|---|---|
| **Given** | Оператор нажал Run на сценарии |
| **When** | Сценарий начинает исполняться |
| **Then** | Studio переключает центральную область в Execution View |
| **And** | Видно: дерево шагов (running/passed/failed), структурированные логи, scanner-алерты в реальном времени |
| **And** | Клик по шагу фильтрует логи и evidence этого шага |

**DoD:**
1. Данные идут через существующий SSE-стрим Live Server, без нового протокола.
2. Нет необходимости открывать отдельную вкладку.
3. Шаг selection фильтрует связанные данные.
4. Execution View read-only, не меняет wired.

**Out of scope:** War Zone, Rewind, Forensics (это Major 2).

---

### 1.2. Живой экран Grid внутри Studio

**Intent:** Оператор видит клики Playwright/Selenium прямо в панели Studio, без отдельной noVNC-вкладки.

| | |
|---|---|
| **Given** | Запущен браузерный сценарий в Selenium Grid |
| **When** | Оператор переключается на вкладку «Браузер» в Execution View |
| **Then** | Внутри панели — живой холст с экраном удалённого браузера |
| **And** | Подсвечиваются координаты кликов и вводимый текст |

**DoD:**
1. Видеопоток/скриншот-трансляция стабильно обновляется в React-компоненте.
2. При падении теста холст сохраняет последний кадр с ошибкой.
3. Не открывается отдельный порт noVNC.

**Out of scope:** Ручное управление браузером (только просмотр).

### 1.3. Legacy sunset

**Intent:** Старый HTML-монитор уходит, Live Server остаётся чистым API/SSE бэкендом.

| | |
|---|---|
| **Given** | Studio показывает полноценный Execution View |
| **When** | Открыт корень `:8767/` |
| **Then** | Редирект в Studio на историю запусков |

**DoD:**

2. SSE и API `/api/stream`, `/api/meta` работают без изменений.

**Out of scope:** Изменение формата SSE-сообщений.

# Major 2: `SIGNATURE-REWIND-POC` — фирменный покадровый скраббер

**Что:** Один ползунок синхронно двигает всё: лу́чи атак, телеметрию, видео, логи, scanner-алерты и подсказки Buddy. Фирменная фича PrettyK.

**Зависимость:** Execution View из Major 1 (Rewind поверх того же run context). Можно стартовать MVP Rewind на View 1 без War Zone.

---

### 2.1. Единая временна́я шкала и синхронный скраббер

**Intent:** Оператор плавно двигает один ползунок и всё (лучи, логи, графики, видео) синхронно перемещается в выбранный момент.

| | |
|---|---|
| **Given** | Завершённый или идущий прогон |
| **When** | Оператор перетаскивает ползунок на `00:14.82` |
| **Then** | Лучи атак — в положении на 14.82 |
| **And** | Телеметрия показывает данные на этот момент |
| **And** | Видео/снэпшот браузера показывает состояние на 14.82 |
| **And** | Лента логов прокручена к строкам этого момента |
| **And** | scanner-алерты показывают состояние на 14.82 |

**DoD:**
1. Движение назад полностью обратимо: лучи втягиваются, алерты схлопываются.
2. Без повторных сетевых запросов — чистый replay сохранённых данных.
3. Отзывчивость скраббинга: 60 fps на среднестатистическом прогоне, без длительных просадок.
4. Живой раннер и исторический replay явно различимы в UI (индикатор Live / Replay).

**Out of scope:** Перезапуск атаки с этой точки (rerun). Rewind — только воспроизведение.

---

### 2.2. Детерминированная проекция лучей

**Intent:** Лучи на арене — не случайная анимация, а точная визуальная проекция реальных событий из словарей фаззера.

| | |
|---|---|
| **Given** | Фаззер отправил вектор из словаря |
| **When** | Ползунок проходит момент отправки |
| **Then** | Луч летит от Fuzzer к Target через scanner-узел |
| **And** | Цвет и финальное состояние луча соответствуют статусу ответа и наличию finding |
| **And** | Клик по лучу — provenance: словарь, entry, payload hash, endpoint, статус |
| **And** | При движении назад луч втягивается обратно детерминированно |

**DoD:**
1. Луч всегда выглядит одинаково на одном и том же `t`.
2. Никакой случайной генерации — seed от event_id/payload_hash.
3. Словари, entry и payload provenance честно отображаются; raw payload — под policy/redaction.

**Out of scope:** WebGL, тысячи одновременных лучей (старт — SVG/DOM).

---

### 2.3. Buddy как хроно-навигатор

**Intent:** Buddy помогает находить критические моменты и объясняет, что произошло.

| | |
|---|---|
| **Given** | На таймлайне есть маркеры findings |
| **When** | Оператор подводит ползунок к маркеру |
| **Then** | Ползунок мягко примагничивается к точному моменту |
| **And** | Buddy показывает: какой вектор из словаря сработал и почему |
| **And** | «Разбери кадр» — цепочка: вектор → ответ → алерт → рекомендация |

**DoD:**
1. Buddy опирается только на факты текущего шага и лога.
2. Различает факт и гипотезу.
3. AirGap: локальный Qwen. Non-AirGap: опционально Gemini.
4. Сам не выполняет SSH/команды, не меняет run, не придумывает причинность.

**Out of scope:** Автоисправление кода, самостоятельный rerun, raw secret/payload без policy.

---

### 2.4. Deep Forensics foundation (View 3)

**Intent:** Оператор видит сопоставление «что отправил PrettyK» ↔ «что в логах scanner и бэкенда».

| | |
|---|---|
| **Given** | Оператор выбрал шаг в Deep Forensics |
| **When** | Открывается карточка расследования |
| **Then** | Видно: RAW-запрос/ответ, срез логов scanner, trace value, кнопка копирования grep-команды |
| **And** | Если внешний коннектор не настроен: честная плашка `Local evidence only` |

**DoD:**
1. Быстрый переход между соседними запросами сессии.
2. Сквозной заголовок `X-PrettyK-Trace` во всех исходящих запросах.

**Out of scope:** SSH/Splunk execution без подтверждения оператора, AI remote commands.
