## 1. Сводка проблем по скриншотам

1. **Правая панель перегружена мусором:** вкладки «Дерево», «Инспектор» и «Diff» захламляют рабочее пространство автора.
2. **Искусственный раскол холста:** вверху висит переключатель «Сущности / Сценарии» (2-й скриншот). Сценарии живут отдельно от сущностей.
3. **Уродливые белые плашки на холсте (1-й скриншот):** ноды рендерятся дефолтным белым прямоугольником ReactFlow (`#ffffff`), не имеют кастомного темного оформления.
4. **Хаотичное расположение нод:** карточки разбросаны без структуры вместо канонической схемы «4 угла + центр».
5. **Заблокированное перемещение:** ноды залочены (`draggable: false`), оператор не может двигать сценарии и профили авторизации по холсту.

## 2. Каноническая схема размещения (4 Угла + Центр)

Все сущности и сценарии живут **на одном едином холсте** (ReactFlow).

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                             ЕДИНЫЙ ХОЛСТ СТУДИИ                             │
│                                                                             │
│  [ВЕРХ-ЛЕВО: #38BDF8]                                [ВЕРХ-ПРАВО: #22C55E]  │
│  ┌────────────────────────┐                    ┌────────────────────────┐   │
│  │    Модели страниц      │                    │     Модули данных      │   │
│  │   (Page Models) [ 3 ]  │                    │   (Data Modules) [ 2 ] │   │
│  └────────────────────────┘                    └────────────────────────┘   │
│                                                                             │
│                            [ЦЕНТР: СЦЕНАРИИ]                                │
│                     ┌───────────────────────────────┐                       │
│                     │ ▼ Сценарий: Smoke Auth [5]    │                       │
│                     │   ├─ ● 1. Open /login         │                       │
│                     │   ├─ ● 2. Fill #email, #pass  │                       │
│                     │   └─ ● 3. Click #submit       │                       │
│                     └───────────────────────────────┘                       │
│                                                                             │
│                       [ЦЕНТР: АВТОРИЗАЦИЯ]                                  │
│                     ┌───────────────────────────────┐                       │
│                     │ 🔑 Профиль авторизации: Bearer│                       │
│                     │    JWT Token / Session Cookie │                       │
│                     └───────────────────────────────┘                       │
│                                                                             │
│  [НИЗ-ЛЕВО: #F59E0B]                                  [НИЗ-ПРАВО: #A855F7]  │
│  ┌────────────────────────┐                    ┌────────────────────────┐   │
│  │        Фаззеры         │                    │ Коннекторы и Интеграции│   │
│  │     (Fuzzers) [ 1 ]    │                    │   (Connectors) [ 0 ]   │   │
│  └────────────────────────┘                    └────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### Цвета и назначение угловых нод (Corner Nodes):
- **Верхний левый:** `Модели страниц` (`#38BDF8` — Cyan).
- **Верхний правый:** `Модули данных` (`#22C55E` — Green).
- **Нижний левый:** `Фаззеры` (`#F59E0B` — Amber).
- **Нижний правый:** `Коннекторы и интеграции` (`#A855F7` — Purple).

### Центр холста (Center Flow):
- **Сценарии (Scenarios):** Сворачиваемые деки (`ScenarioDeckNode`) с раскрывающимися шагами (`StepPillRow`), кнопками добавления шагов, LED-статусами прогона и возможностью свободного перетаскивания.
- **Профили авторизации (Auth Profiles):** Карточка авторизации с методами входа (JWT, Basic, Cookie), также свободно перемещаемая.

## 3. Детализация 7 пунктов задачи

### Пункт 1: Выпилить вкладку «Дерево» из правой панели
- **Что сделать:** Удалить вкладку `tree` (`FolderTree`) из правой панели `StudioV2.tsx`.
- **Обоснование:** Структура проекта полностью и наглядно представлена прямо на холсте (угловые категории + сценарии). Дерево в правой панели — дублирование и визуальный шум.

### Пункт 2: Убрать вкладку «Инспектор»
- **Что сделать:** Удалить вкладку `inspector` (`Info`) и компонент `InspectorPanel`.
- **Обоснование:** Статистика сценариев (кол-во шагов, статус) уже встроена в плашку сценария на холсте. Редактирование конкретных шагов и полей происходит по клику на ноду либо в панели «Код».

### Пункт 3: Выпилить вкладку «Diff»
- **Что сделать:** Удалить вкладку `diff` (`GitCompare`) и компонент `DiffPanel` из `StudioV2.tsx`.
- **Обоснование:** Студия — среда визуального моделирования и запуска, Git-diff в ней не нужен.

### Пункт 4: Ликвидировать раскол «Сущности / Сценарии» (Единый холст)
- **Что сделать:**
  - Удалить кнопки переключения `<button>Сущности</button>` и `<button>Сценарии</button>` в шапке холста `StudioV2.tsx`.
  - Удалить ветвление `if (mode === "scenarios") return <ScenarioFlow />` в `CanvasV2.tsx`.
  - Встроить сценарии (`ScenarioDeckNode`) прямо в массив нод общего холста по центру.
  - Сценарии рендерятся в виде аккордеонов (сворачиваемые/разворачиваемые карточки с шагами).

### Пункт 5: Ликвидировать белые карточки — стиль Obsidian Dark
- **Что сделать:**
  - Зарегистрировать в `ReactFlow` кастомные `nodeTypes`:
    - `cornerNode`: стилизованная карточка категории (стиль взят из `SanctuaryMapNode` / `CornerNode`);
    - `scenarioDeck`: интерактивная дека сценария со сворачиваемыми шагами (`ScenarioDeckNode`);
    - `authDeck`: карточка авторизации.
  - Применить стили:
    - Фон карточки: `#0B0F17` / `#0F172A`.
    - Верхний акцентный бордер: `2px solid <color>`.
    - Рамка: `1px solid rgba(255, 255, 255, 0.08)`.
    - Скругление: `borderRadius: 8px`.
    - Типографика: `Golos UI`, цвет текста `#E2E8F0`, счетчик в pill-бейдже `#1E293B`.
    - Фон канваса: `#080D1A` с точками `#1E293B` (Obsidian Dark).

### Пункт 6: Свободное перемещение сценариев и авторизации
- **Что сделать:**
  - Для нод сценариев (`scenarios`) и профилей авторизации (`auth`) выставить `draggable: true`.
  - В `ReactFlow` включить `nodesDraggable={true}`.
  - Обеспечить корректный обработчик `onNodesChange`, чтобы при перетаскивании координаты нод обновлялись плавно без дерганий.
  - (Опционально) Угловые ноды категорий можно оставить закрепленными по умолчанию либо также разрешить двигать.

### Пункт 7: Источники стилей из кодовой базы
- **`frontend/src/sanctuary/SanctuaryMapNode.tsx`** — референс темных нод, LED-индикаторов статусов и неоновых бордеров.
- **`frontend/src/studio/ScenarioDeckNode.tsx`** — готовый компонент аккордеона сценария со строками шагов `StepPillRow`.
- **`frontend/src/design-playground/data/canvasBackdrops.ts`** — точные цветовые токены Obsidian Dark (`#080D1A`, `#0C1220`, `rgba(56, 189, 248, 0.18)`).

## 4. Итоговая конфигурация правой панели Studio

В правой панели `StudioV2` остаются только нужные инструменты:
1. **Код** (`Code2`) — Monaco Editor для прямого редактирования DSL выбранной сущности / шага.
2. **Браузер** (`Monitor`) — Live noVNC / preview целевого стенда.
3. **Buddy Dock** — умный ассистент по архитектуре и автотестам.
4. **Консоль** (снизу) — сворачиваемая панель вывода логов и исполнения.
