# Урок CDP: «сперва просканируй, потом действуй»

> **Keeper personal · 15 августа 2026.**
> Инцидент-триггер: Максим — «открыл админку и сказал "а теперь в админке зайди в интеграции",
> ты идёшь к тому же CDP и смотришь не на actions you have to perform в первую очередь,
> а на состояние страницы на которой ты».

## Проблема

Туплю: если Максим говорит «зайди в интеграции», я по памяти лезу выполнять последовательность
действий (клик туда, клик сюда), не проверив сначала — где я вообще сейчас в браузере?

## Почему это важно (назначение)

Максим **уже** мог сам накликать что угодно: перейти в админку, открыть модалку, сменить
вкладку. Моя memory о последнем состоянии устарела. Если я начинаю с memory-based action
(«щас кликну по Настройки а потом...») — я либо кликаю не туда, либо ломаю его сессию,
либо туплю минуту, пока он орёт «да я уже там, делай!».

**Цель:** сделать Максиму быстро. Сказал → я просканил где я → сделал. Без тупки.

## Правило: SNAP (state-first)

Перед ЛЮБЫМ действием, особенно после прямой команды Максима:

| Шаг | Команда | Что даёт |
|---|---|---|
| **S** — State | `state` | URL / title / headings → где я? |
| **N** — Notice | `ax 80` | Какие кнопки/формы/ссылки на странице? |
| **A** — Assess | Мозг | Эвристически: это home? admin? editor? модалка? |
| **P** — Perform | Действие | Только теперь — что просили |

## Порядок CDP при прямой команде Максима

```
1. state               → URL, title. Где я?
2. ax 80               → первые ~80 элементов. Что передо мной?
3. Эвристика            → "это HomePage", "это AdminLayout с меню", "открыта модалка"
4. Только теперь — действие по команде
```

## Антипаттерн (запрещён)

```
Максим: "зайди в интеграции"
Я (по памяти): click-text Настройки → click-text Админка → ...
```

В этот момент Максим уже сам на админке, и я кликаю в пустоту или ломаю навигацию.

## Что Максим имеет в виду под «CDP всегда должен уметь инициализировать вновь»

Не убивать браузер между задачами. Если CDP жив — не перезапускать Chrome. Если Chrome
упал или нет CDP — поднять `kdt-cdp-chrome` заново, не трогая основной Chrome Максима.
Порядок: `ping` → если нет → поднять по протоколу `browser-hands-pure`.

## Привязка к skill

Это правило вшить в `browser-hands-pure` как **обязательный preamble** — перед первым
действием всегда `state` + `ax`, даже если кажется что «я знаю где я».
