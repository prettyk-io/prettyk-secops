# Начало работы

Цель этой страницы — открыть Редактор, создать простой сценарий и скачать валидный манифест. Браузер и ZAP пока не нужны.

## 1. Подготовить окружение

Нужны:

- Windows 10/11 и PowerShell;
- Python 3.11;
- Node.js 20.19+ или 22.12+;
- Git.

Из корня репозитория:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r orchestrator\requirements.txt

Set-Location cosmo
npm.cmd ci
Set-Location ..
```

Если PowerShell запрещает активацию виртуального окружения, это не мешает работе: команды ниже вызывают `python.exe` напрямую.

## 2. Открыть Редактор

```powershell
.\.cursor\scripts\lab_ensure_ui.ps1
```

Откройте [http://localhost:5173/](http://localhost:5173/) и перейдите в **Редактор**.

Ожидаемый результат: форма логина или shell Редактора (не белый экран). Для этого шага Docker не нужен.  
Старт UI + DoD после инвазивного FE: [`stand.md`](stand.md) § «Запустить только Редактор» · [`agent-entrypoint.md`](agent-entrypoint.md) § «DoD: живой Editor».

## 3. Создать сценарий

В разделе **Сценарии** нажмите `+`, задайте имя `first_check` и вставьте:

```text
Открыть $base_url
ЖдатьЭлемент css body 10
ПроверитьТекстНаСтранице "OWASP Juice Shop" 10
```

Имя сценария пишется латиницей, может содержать цифры и `_`, но не пробелы.

Что делает сценарий:

1. открывает адрес из поля `base_url_override`;
2. ждёт появления страницы;
3. проверяет, что на странице есть нужный текст.

Подробнее о командах: [справочник языка](reference/language.md).

## 4. Проверить сценарий

Нажмите **«Валидировать»** на вкладке сценария.

Ожидаемый результат: Редактор не показывает ошибок. WireK справа содержит производное представление команд.

Валидация проверяет текст, но не открывает браузер и не выполняет сценарий.

## 5. Скачать манифест

Перейдите в **Форму** и убедитесь, что адрес цели задан в поле Base URL. Для локального Juice Shop:

```text
http://juice-shop:3000
```

Нажмите **«Скачать манифест»**. Это авторская копия: её можно снова загрузить в Редактор и продолжить работу.

Проверьте весь файл без запуска:

```powershell
.\.venv\Scripts\python.exe orchestrator\main.py `
  --manifest "$env:USERPROFILE\Downloads\manifest.json" `
  --validate-only
```

Подставьте фактическое имя скачанного файла. Код `0` означает, что структура и сценарии валидны.

## 6. Выполнить проверку

Для полного запуска понадобятся Docker, Juice Shop, ZAP, браузер и отчётность. Продолжите по инструкции [«Первая проверка Juice Shop»](guides/first-juice-check.md).

## Если что-то не получилось

- Редактор не открывается — выполните `lab_ensure_ui.ps1` ещё раз и проверьте сообщение в терминале.
- Разделы дерева недоступны — загрузите готовый пример `docs/releases/manifest_juice_shop_test.json`.
- `$base_url` не определён — заполните Base URL в Форме и скачайте манифест заново.
- Validate показывает ошибку — начните с первой отмеченной строки; остальные ошибки часто следуют из неё.
