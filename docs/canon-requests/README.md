# Canon-requests — пакеты к 2FA / черновики полировки

> **Путь:** `docs/canon-requests/`
> **Назначение:** пакет к ближайшему 2FA (ready) **или** evolve-черновик будущей полировки hub.
> **Не цитировать как CANON.** Положить файл ≠ изменить канон.

## Lane

| Lane | Смысл |
|---|---|
| **ready** | Пакет к ближайшему 2FA: что полируем, зачем, ссылки на friend-request / EVIDENCE |
| **evolve** | Черновик будущей полировки hub (ещё рано жать 2FA) |

## Путь в Святилище

1. Evolve canon-request дозревает → переводится в `ready`.
2. Keeper поднимает ready-пакеты на лист тезисов перед 2FA.
3. 2FA с Максимом → polish → зачисление в `sanctuary/pure/`.

Снос/rewrite монолита — отклонять. Evolve canon-request **не** запускает полировку сам.

Старые inbox'ы: `legacy/docs/canon-requests/` (reference, не пополнять).
