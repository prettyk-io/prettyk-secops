## Этап 1. Извлечение форм и полей из HTML (DOM Analysis)

Для **каждого** из 18 HTML-файлов извлеки структурированный JSON со следующими данными:

1. **Идентификация экрана:**
   - Название страницы / модального окна.
   - Хлебные крошки (Breadcrumbs) и URL пути.
2. **Все элементы ввода (Inputs, Selects, Radios, Checkboxes, Textareas, Toggles):**
   - Точный `label` (русский текст).
   - Атрибуты `id`, `name`, `placeholder`.
   - Обязательность (`required` / звёздочка `*`).
   - Подсказки (`tooltip` / help text).
   - Опции для выпадающих списков (`select options`).
   - Значения по умолчанию (`default values`).
   - Условная видимость (например: «при выборе типа X появляются поля Y и Z»).
3. **Кнопки действий (CTA):**
   - Названия кнопок («Сохранить», «Создать», «Отменить», «Архивировать», «Заказать ВМ»).
   - Деструктивные действия (удаление, откат).

## Этап 3. Анализ JS-бандла `app-5e2d9864.js` (8.16 MB)

Напиши скрипт на Python (с использованием `re` / AST парсинга), который просканирует `app-5e2d9864.js` и вытащит:

1. **Полную карту REST API:**
   - Регулярка: `["']/(api|v1)/[a-zA-Z0-9_\-\/{}]*["']`.
   - Сгруппируй все эндпоинты по сущностям:
     - `/api/projects/*`
     - `/api/pipelines/*`
     - `/api/runtimes/*`
     - `/api/common_notifications/*`
     - `/api/core_services/*`
     - `/api/validities/*`
     - `/api/metrics/*`
2. **Словари и Enums (Справочники):**
   - Типы приложений (`Крейсер`, `Вселенная`, `Модуль`, `Космостанция`, `Гиперпривод`...).
   - Роли участников (`IT-лидер`, `Руководитель разработки`, `Разработчик`, `Тестировщик`, `Администратор КИТС`, `Релиз менеджер`, `Эксперт ИБ`...).
   - Шаги жизненного цикла (`build`, `unit_tests`, `docs_generation`, `sonar_qube`, `ptai`, `solar_appscreener`, `trivy`, `codescoring`, `sandbox`, `kcs`, `deployment`, `autotests`, `blackbox`, `owasp_dast`).
   - Типы уведомлений и адресаты (`Все пользователи`, `Только администраторы`, `Команда`, `Персональное`).
3. **Клиентские схемы валидации:**
   - Regex-паттерны названий проектов/кодов.
   - Ограничения длины строк, диапазоны тайм-аутов, лимиты памяти/CPU.
