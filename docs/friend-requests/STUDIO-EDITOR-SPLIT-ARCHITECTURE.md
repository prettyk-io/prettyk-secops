## 1. Проблема и Архитектурный Замысел

### Проблема:
Текущий `StudioWorkspace` перегружен: в одной рабочей области смешаны чистый кодинг сценариев на DSL, визуальные формы коннекторов (DB, SIEM, Prom, SSH, MQ), модули цепочек, тяжелая станция фаззинга (Burp Intruder) и технический просмотр компилятора `WireK`. Это перегружает DOM, размывает фокус инженера и мешает развивать киллер-фичи (ручной Burp Intruder).

### Замысел:
1. **Studio становится полноправным Хабом Инструментов (Studio Workspace)**.
2. В шапке Studio появляется явный режимный переключатель: **`[ Студия | Редактор ]`** (`[ Studio | Editor ]`).
3. **`Студия` (Visual Front & Attack Hub)** — визуальный центр управления:
   - 💣 **Burp Intruder / Fuzzer** — полноценная станция атак (Sniper, Pitchfork, Cluster Bomb, Battering Ram, пресеты словарей, сплит Request/Response).
   - 🔌 **Коннекторы & Инфраструктура** (DB, SIEM, Prometheus, OpenSSH, RabbitMQ/Kafka).
   - 🔑 **Авторизация (Auth Modules)** — сессии, Bearer/OAuth, логин-пайплайны.
   - 📦 **API Chains & Modules** — визуальные цепочки без прямого кодинга.
   - 📂 **Ресурсы и тестовые данные** — словари, таблицы, фикстуры.
4. **`Редактор` (DSL Code Editor)** — чистая, сфокусированная среда написания скриптов `PrettyK`:
   - Monaco Canvas (канон 32 строки).
   - AST-линтер, автокомплит MethodId, подсказки сигнатур, отсутствие посторонних визуальных форм.
5. **Выпил WireK из UI**:
   - `WireK` — внутренняя промежуточная репрезентация (AST / wire format) для раннера. Пользователю в UI она не нужна.
   - Все UI-табы `WireK`, сплит-превью и кнопки переключения на `wirek` удаляются из интерфейса. Трансляция остаётся под капотом.
