# ALLURE3-SECOPS-BRAND-AND-INSTANCE: окультуривание Allure3 под бренд SecOps Lab + per-instance история

`lane: ready` · Эпики `AL3-BRAND` + `AL3-INSTANCE` (закрыты 16 авг 2026).

## Статус (as-built, 16 авг)

Все карточки обоих эпиков закрыты, проверены в рантайме на `:5050` и зафиксированы:

1. **AL3-BRAND (Брендинг и внешний вид):**
   - **AL3-B1** (Flash) — Фирменный SVG-wordmark `SecOps Lab` в хедере отчёта, градиентный маркер-бар, правильные отступы.
   - **AL3-B2** (Flash + Bro) — Overview-дашборд: статус-карточки (Всего / Успешно / Провалено / Сломано / Пропущено / Длительность), Quality Gate бейдж, аккуратная сетка.
   - **AL3-B3** (Flash) — Тёмная тема коробки (`#0d1117`, `#161b22`, `#10151c`), скругления строго 5–6px, системные шрифты `Segoe UI` / `JetBrains Mono`.
   - **AL3-B4** (Flash) — Русские лейблы переменных/окружения/категорий. Полная изоляция от сети (zero telemetry, GTM/gtag вырезан, внешние CDN отсутствуют).
   - **AL3-B5** (Bro) — Разделение Overview (`index.html`) и полного SPA (`full.html`). В SPA встроена плавающая кнопка возврата «← К обзору SecOps Lab».

2. **AL3-INSTANCE (История и App-дашборд):**
   - **AL3-I1** (Bro + Flash) — Приоритет `project_id = check_id` (история проверок накапливается в одном отчёте по инстансу вместо потери контекста на каждый run). Лента истории запусков внизу Overview.
   - **AL3-I2** (Bro + Flash) — Автономный App-дашборд (`/apps` и `/app/{app_code}`) на основе `runs_index.ndjson` с карточками deployments и статусами проверок.
   - **AL3-I3** (Flash) — Кликабельные категории дефектов: при >1 теста ведут в `full.html#suites/{id}`.

## Тезис

Allure3 трансформирован из дефолтного стороннего инструмента в органичную часть коробки SecOps Lab:
1. **Визуальная идентичность:** единый визуальный язык с Editor и Admin, тёмная тема, лаконичные скругления.
2. **Безопасность (Bank-grade):** полный запрет внешних сетевых запросов и телеметрии.
3. **Непрерывность истории:** отчёты привязаны к инстансу проверки (`check_id`), сохраняя ретроспективу прогонов.
4. **Агрегация по сервисам:** дашборд приложений объединяет разрозненные проверки одного сервиса.
