# EDITOR-PREMIUM-STUDIO: Архитектура дорогого рабочего пространства и визуальный монолит редактора

`lane: ready` · Friend-request на окультуривание и премиализацию рабочей среды Studio / Editor (17 авг 2026).

---

## 1. Контекст и проблема (Почему текущий Editor выглядит дешевле)

Текущий интерфейс Studio/Editor (`StudioWorkspace`, `SecOpsMark`, `PrettyKEditorMark`, `tokens.ts`) собирался итеративно под функциональные задачи рантайма, из-за чего накопился визуальный «франкенштейн», снижающий воспринимаемую ценность продукта:

1. **Каша в шапке (Header Overload):**
   - Одновременное соседство разнородных элементов: target-bracket скобка, жирный текст `SecOps` из Segoe UI, рядом отдельный SVG `PrettyK EDITOR` с самопальной технической полоской и другим кеглем.
   - Нет чистого брендового якоря — шапка выглядит как тулбар админки середины 2010-х, а не специализированная IDE корпоративного класса за $50k+.
2. **Плоские «слепые» контейнеры (No Depth Hierarchy):**
   - Дерево блоков слева и холст Monaco справа разделены глухим серым бордером `#3A4150` без ощущения глубины.
   - Все поверхности имеют близкую яркость, из-за чего глаз быстро устаёт и теряет фокус на активном документе.
3. **Грубый серый пластик и резкие подсветки:**
   - Серые рамки и разделители спорят с текстом DSL.
   - Подсветка активной вкладки `tabActiveBg` / `tabInk` использует резкий циановый оттенок без мягкой оптической плотности.

## 2. Архитектурные тезисы редизайна (Что делаем)

Рассматриваем **Editor как самостоятельный флагманский продукт** в линейке SecOps Lab:

### Т1. Чистый монолитный Lockup в шапке (Clean Product Branding)
Вместо склейки кусков делаем строгий двухуровневый лок-ап:
- **`Pretty<`** — мастербренд (белый цвет `#F8FAFC` + шеврон в фирменном `#38BDF8`).
- **Тонкий вертикальный разделитель** `rgba(148, 163, 184, 0.25)` (высота 16px).
- **`EDITOR`** — суб-бейдж капсом, набранный шрифтом `Golos UI` / `JetBrains Mono`, трекинг `0.08em`, в благородном прохладном синем цвете `#8AB4F8`.
- **Сегментированный переключатель режима `PrettyK | WireK`** — компактный pill-сплиттер на тулбаре со скруглениями 4–5px, без лишнего визуального шума.

### Т2. Трёхслойная глубина поверхностей (Three-Tier Depth Hierarchy)
Внедряем профессиональную архитектуру слоёв в духе современных IDE (Linear, Zed, JetBrains Fleet):

```text
┌────────────────────────────────────────────────────────────────────────┐
│ Слой 0: Внешний каркас / Хедер (#080A0F) — глубочайший ночной тон      │
├──────────────────────┬─────────────────────────────────────────────────┤
│ Слой 1: Сайдбар      │ Слой 2: Холст редактора Monaco (#0F141C)        │
│ Дерево сценариев,    │ - Фокусная рабочая зона                         │
│ модулей, ресурсов    │ - Мягкий контраст под синтаксис PrettyK / WireK │
│ (#0D1117)            │ - Тонкий маркер активной строки                 │
├──────────────────────┴─────────────────────────────────────────────────┤
│ Слой 1: Статус-бар / Инфо-панель (#0D1117)                             │
└────────────────────────────────────────────────────────────────────────┘
```

- **Стекольные микробордеры (Glass Borders):** Все границы между панелями заменяются с грубого `#3A4150` на ультра-тонкий `1px solid rgba(255, 255, 255, 0.06)`. В тёмной теме это даёт вид монолитного бесшовного стекла.

### Т3. Премиальная система вкладок и фокуса (Subtle Tab Accents)
- **Активная вкладка:** Тонкая верхняя полоска `1.5px` фирменного цвета `#38BDF8` + мягкая фоновая заливка `rgba(56, 189, 248, 0.06)` со скруглением верхних углов 4px.
- **Неактивные вкладки:** Прозрачный фон, приглушённый текст `#94A3B8`, подсветка при наведении `rgba(255, 255, 255, 0.03)`.
- **Gutter и номера строк:** Чистый монохром с зазором в 32 строки по канону `constructor-30-lines.mdc`, приглушённые номера строк `#475569`, мягкая подсветка текущей строки `rgba(56, 189, 248, 0.04)`.

### Т4. Изолированная цветовая дифференциация режимов
- **Режим PrettyK (Основной):** Акцент `#38BDF8` (Electric Ice Blue).
- **Режим WireK (Проводной / DSL):** Акцент `#8AB4F8` (Soft Slate Blue) + сдержанный моноширинный тон.
- **Fuzzer / Attack Wave:** Благородный акцент `#7A1FA2` / `#522E90` (Vibrant / Indigo Violet) на бейджах и фаззинг-модулях, подчеркивающий боевой режим безопасности.

## 4. Честная «не делаем» (Out-of-scope)

1. **Не ломаем рантайм Monaco и горячие клавиши:** Модели данных, автокомплит, провайдеры навигации и pad 32 строк остаются нетронутыми.
2. **Не делаем фиолетовые фоны в редакторе:** Фиолетовый `#7A1FA2` живёт только в бейджах Fuzzer и спец-маркерах, рабочие холсты остаются в строгом холодном сине-чёрном спектре.
3. **Не раздуваем скругления:** Радиусы строго 4–6px по канону shell/Ant.
