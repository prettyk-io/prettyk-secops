## 1. Тезис: Зачем безопаснику интерактивный запуск

В легаси-инструментах (Burp, ZAP, Acunetix, Checkmarx) запуск проверки — это унылый серый прогресс-бар 0..100% и бегущие логи. Оператор сидит вслепую, не понимая физику происходящего: где находится сканер, куда бьёт фаззер, где застрял запрос.

**В PrettyK мы свободны от внешних рамок и строим то, чего нет на рынке:**
Интерактивный **Tactical Execution Canvas (War Room)** на базе `@xyflow/react` v12 + легковесного 2D Canvas Particle Engine.

При нажатии «Инициировать проверку» Студия не просто начинает фоновый прогон — она перестраивается в живой командный пункт:
1. **Перестройка рабочего пространства (War Room Layout Shift):** Редактор кода плавно уступает место полноэкранному графовому холсту, трансформируясь в боковой HUD-монитор телеметрии.
2. **Кинематографичная камера (`useReactFlow`):** Динамический фокус на активных узлах (Auth → Page Models → Scenarios → Fuzzers → Reporting).
3. **Живой конвейер шагов (Animated SVG Conveyor):** Световые фотонные импульсы бегут по рёбрам со скоростью реального сетевого ответа.
4. **Залп Фаззера (The Heavy Strike):** Эпичный Zoom-out, периметральная зарядка и веерный лазерный обстрел корпуса целевого хоста с частотой реального RPS.
5. **Вспышки аномалий (Anomaly Shockwaves):** При статусе 500 / Time-delay / уязвимости — радиальный световой взрыв (Amber/Magenta) с рождением маркера прямо на графе.

## 2. Баланс: Dream Big, Stay Real (Без дискотеки и WebGL)

Чтобы интерфейс оставался строгим, холодным кибер-инструментом высшего класса, а не мобильной игрой:

| Принцип | Как реализуем | Чего категорически избегаем |
|---|---|---|
| **Честность (Zero Fake FX)** | Скорость, цвет, плотность лучей и вспышек на 100% привязаны к SSE-событиям `diary_bus` и HTTP-телеметрии | Никаких захардкоженных зацикленных гифок или таймеров «для красоты» |
| **0% CPU / 60 FPS** | 2D Canvas + нативные SVG-фильтры + CSS GPU `transform` | Никаких Three.js, Pixi, тяжелых WebGL-шейдеров, жрущих батарею |
| **Эстетика Dark Glass** | Палитра `#0B0F17`, острые 2px лазерные лучи, `#38BDF8` Cyan, `#A855F7` Violet, `#F59E0B` Amber, `#10B981` Emerald | Никаких мультяшных градиентов, круглых пузырей и визуального шума |
| **Тактильный ритм** | Slow-mo нагнетание (зарядка контура) → резкий 200ms burst в момент атаки | Монотонное непрерывное мигание, от которого устают глаза |

## 4. As-Built фундамент (Уже в репозитории)

Нам не нужно начинать с нуля — в репозитории уже готовы ключевые кирпичи:
1. **`@xyflow/react` v12.11.3** — в `package.json`, прототип нод в `cosmo/src/studio/graph/ScenarioCanvas.tsx`.
2. **`GraphWaveOverlay.tsx`** — чистый высокопроизводительный Canvas 2D движок периметральных волн (с поддержкой `inverted` и `delayOffset`).
3. **`GraphTelemetryOverlay.tsx`** — SVG-слой фотонных импульсов с адаптивной скоростью по latency.
4. **`useGraphTelemetry.ts`** — реактивный хук, читающий Live SSE стрим `:8767/api/diary?channel=telemetry`.
5. **`NodeHudWhisperer.tsx`** — контекстный микро-чип над активным узлом.
6. **`StepLanternLed.tsx`** — 4-состоянийный LED-индикатор в слотах шагов.

## 5. План реализации (Roadmap)

### Этап 1: War Room Layout Switcher (Flash, 3 часа)
- Режим отображения Студии: `pk-studio-workspace--warroom`.
- Плавный CSS Grid переход: граф на 100% ширины, сворачивание редактора в правый floating HUD.
- Автоматическое включение при получении статуса `status: "running"`.

### Этап 2: React Flow Camera Director (`useReactFlow`) (Keeper/Flash, 3 часа)
- Интеграция `useReactFlow` контроллера в `ScenarioCanvas.tsx`.
- Авто-следование камеры за активным узлом (`setCenter` с `duration: 600ms`).
- Режим `zoomTo(0.75)` при переходе на фаззинг/массовую атаку.

### Этап 3: Laser Strike Particle Emitter (Canvas 2D) (Gemini/Boss, 4 часа)
- Компонент `FuzzerStrikeOverlay.tsx` (Canvas 2D overlay).
- Генерация частиц: лазерный луч от ноды источника к цели, радиальный shockwave при фиксации аномалии.
- Прямая связка с событиями фаззера (`fuzz.target_hit`, `fuzz.anomaly`).

### Этап 4: Telemetry Bridge & Anomaly Markers (Boss, 3 часа)
- Передача расширенной телеметрии из `orchestrator/core/fuzzing.py` и `controller.py` в `diary_bus`.
- Отображение интерактивных бейджей находок на канвасе в реальном времени.
