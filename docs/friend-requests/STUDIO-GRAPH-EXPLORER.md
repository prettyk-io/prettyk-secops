# Friend-Request: Графический интерактивный Explorer сущностей в Studio (Node Graph)

> **ID:** `STUDIO-GRAPH-EXPLORER`  
> **Статус:** `ready`  
> **Роль / Исполнитель:** Boss / Flash  
> **Слой:** Frontend (`cosmo/src/studio/graph/`) ↔ JSON Wired

---

## 1. Продуктовая суть и замысел

В режиме **Студии (Studio View)** левая панель (50% экрана) трансформируется из сухой классической древовидной структуры VS Code в **живой топологический граф архитектуры проверки**:
1. **Ядро проверки (Hub Center):** В центре графа располагаются основные сценарии выполнения (`Scenarios`) и профили авторизации (`Auth Profiles`).
2. **Периферийные модули и зависимости (Nodes):**
   - **Модели страниц (Page Models)** — узлы с перечислением локаторов.
   - **Модули данных (Data Modules)** — CSV, JSON, TXT списки URL.
   - **Коннекторы и интеграции (Connectors)** — gRPC, GraphQL, OpenAPI спецификации.
   - **Фаззеры (Fuzzers)** — прилинкованные правила фаззинга параметров.
3. **Интерактивность:** Клик по узлу на графе (Node) фокусирует и открывает панель настройки параметров этой сущности без перехода в чистый Monaco код.

---

## 2. Архитектурный стек и ограничения

1. **Библиотека рендеринга:** `@xyflow/react` (React Flow v12) или легковесный Canvas-renderer.
2. **Управление состоянием:** Внешний контролируемый store (Zustand slice / direct props sync). Состояние графа вычисляется детерминированно из `formData` манифеста (без рассинхронизации).
3. **Стиль узлов (Nodes):**
   - Тёмное стекло (`background: rgba(22, 27, 34, 0.75)`, `backdrop-filter: blur(12px)`).
   - Фирменные 3D-иконки 32x32 на заголовках узлов.
   - Каноничные бейджи статусов связей (Neon Cyan `#38bdf8` для данных, Neon Violet `#a855f7` для Auth, Neon Amber `#f59e0b` для Fuzzers).

---

## 3. Критерии приёмки (DoD)

- [ ] При создании сущности через Action Hub граф автоматически дорисовывает новый узел и анимирует связь с активным сценарием.
- [ ] При клике на узел в графе справа открывается форма параметров сущности.
- [ ] Drag & Drop узлов сохраняет координаты в локальном состоянии сессии.
- [ ] Производительность: рендеринг графа до 50 узлов не вызывает просадки FPS (< 16ms на кадр).
