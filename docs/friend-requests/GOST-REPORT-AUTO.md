# GOST-REPORT-AUTO: Автоматическая генерация ГОСТ-Акта из Evidence + Findings

> `lane: ready` · 27 авг 2026. Research: [`cosmoport-domain-model.md`](../research/2026-08-27-cosmoport-domain-model.md) · [`cosmoport-ib-poc.md`](cosmoport-ib-poc.md).

## Тезис

По завершении Run, PrettyK автоматически формирует ГОСТ-Акт: титульная страница с реквизитами, таблица находок с severity и evidence-ссылками, заключение о допуске, подписи Исполнителя и Проверившего. Акт собирается из данных Run (Evidence Chain + Findings + Gate decisions), а не заполняется вручную.

## Ключевые свойства

- **Автоматическая сборка.** Все данные уже есть в системе: Run metadata, Findings, Gate decisions, Evidence references. Акт — это рендеринг существующих данных.
- **ГОСТ-формат.** Титульная страница, нормативная база (683-П, 757-П, ГОСТ Р 57580.1), контур испытаний, таблица находок, заключение, подписи.
- **Брендирование.** Логотип ЦБ (из пакета `cosmo-custom`), логотип PrettyK. Коробка не содержит банковских брендов.
- **Подписи.** Минимально: Исполнитель (sec_expert) и Проверил (admin_sec). В v1 — имена и даты, не криптография.
- **Не «ещё один Word». Акт рендерится в HTML (для просмотра) и PDF (для печати/архива).**
- **Привязка к deploy.** Акт сохраняется в deployStore с привязкой к project_id/deploy_id.

## Что уже есть

- `cbr-specific/` — локально (не в git): бланки, profile.ts с нормами, letterhead логотипа ЦБ, пример ТЗ (385 строк HTML), пример Акта.
- `cosmoport-ib-poc.md` — сценарий: Администратор ИБ утверждает Акт, admission gate пройден.

## Что нужно построить

- Report engine: сборка HTML из Run данных.
- Шаблон ГОСТ-Акта (HTML/CSS).
- PDF-рендеринг (Puppeteer/Playwright headless или wkhtmltopdf).
- Подстановка данных: Run metadata, Findings (severity + title + evidence refs + рекомендации), Gate decisions, подписи.
- Сохранение в deployStore с привязкой к deploy_id.
- Механизм брендирования: коробка рендерит базовый шаблон, пак подставляет логотип и нормативную базу.

## Честная «не обещаем»

- Полноценный ГОСТ-редактор (редактирование Акта после генерации) — out of scope v1. Акт генерируется as-is.
- Электронная подпись (криптография) — out of scope v1.
- Множество форматов отчёта — v1: HTML + PDF.
